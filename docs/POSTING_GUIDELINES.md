# Unearth posting guidelines

**Public places only.**

Unearth is for little-known spots other people can actually visit. Keep finds helpful, respectful, and real.

## Allowed

- Public parks, trails, viewpoints, cafés, shops, street-food spots, and similar places open to the public
- Honest notes about what you liked or didn’t like
- Clear pins so someone else can find the place

## Not allowed

- **Private property** — homes, apartments, private gardens, gated communities, or anywhere guests are not welcome
- **Unsafe or restricted** sites (active construction, trespassing, dangerous cliffs without public access)
- Spam, scams, harassment, or misleading locations
- Personal data about other people (phone numbers, home addresses, etc.)
- Illegal activity

## Tips for a good find

1. Pin the entrance or the spot people should aim for.
2. Write why it’s a gem in plain language (10+ characters).
3. Use tags sparingly so others can dig by vibe.

Reports help keep Dig trustworthy — use **Report** on a gem or find if something breaks these guidelines.
